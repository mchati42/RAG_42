WHAT IS RAG? (Simple Explanation)
================================================================================

RAG = Retrieval-Augmented Generation

Think of it like this:
- You have a big pile of code files (like a library)
- Someone asks you a question
- You find the right pages in your pile that answer the question
- You give those pages to a small AI helper
- The AI helper reads those pages and writes an answer

That's RAG!

The Project Needs 4 Steps:
1. INDEXING = Organize the code files so you can search them fast
2. RETRIEVAL = Find the best matching pieces of code for a question
3. AUGMENTING = Pick the good pieces and give them to the AI
4. GENERATING = Let the AI write the final answer

TROUBLESHOOTING TIPS
================================================================================

Problem: "Index takes too long"
Solution: Make chunks smaller? Or use simpler search algorithm?

Problem: "Search doesn't find right answer"
Solution: Check your scoring method. Is TF-IDF working? Try BM25?

Problem: "AI answer is wrong"
Solution: Give it better code chunks? Your retrieval might be bad?

Problem: "Code is slow"
Solution: Add progress bars? Save index to disk? Use caching?

Problem: "Don't understand a requirement"
Solution: Read the chapter again. Ask yourself: What does this word mean?
